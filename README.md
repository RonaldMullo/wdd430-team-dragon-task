# Dragon Task 2.0

Dragon Task 2.0 is a task management and planning application developed as a team project for WDD430 – Web Full-Stack Development.

The application is designed to help users organize their tasks by categories and priorities, manage daily activities, and keep track of unfinished tasks. The project will be developed progressively using Next.js, TypeScript, Tailwind CSS, and server-side API routes.

## Main Features

- Create and manage tasks
- Organize tasks by categories
- Assign priorities to tasks
- Daily task planning
- Reschedule unfinished tasks
- Responsive user interface
